# 🎮 Tic-Tac-Toe with AI | Python & Artificial Intelligence Bootcamp - DevTown

This repository contains a Python-based implementation of the classic **Tic-Tac-Toe** game. Built as part of the **Python and Artificial Intelligence Bootcamp** conducted by **DevTown**, the game offers both multiplayer and single-player (vs AI) modes.

The AI opponent utilizes the **Minimax algorithm**, enabling it to make optimal moves and never lose!

---

## 🧠 Features

- **Single Player Mode**: Play against an unbeatable AI (uses Minimax algorithm).
- **Multiplayer Mode**: Two players can compete locally.
- **Console-based UI**: Simple text-based interface using Python's standard I/O.
- **Error Checking**: Prevents illegal moves and notifies the user.
- **Game Result Analysis**: Detects draw or winning conditions accurately.

## 📌 How to Play

- You'll be prompted to choose:
  - `1` for Single Player (You vs AI)
  - `2` for Multiplayer (Player X vs Player O)
- For each move, input a position from **1 to 9** as shown below:
  ```
  1 | 2 | 3
  ---------
  4 | 5 | 6
  ---------
  7 | 8 | 9
  ```

---

## 🔍 Algorithms Used

- **Minimax Algorithm**: Used by the AI to choose the best possible move by simulating all possible future states of the game.
- **Board Evaluation**: Checks winning combinations across rows, columns, and diagonals.
